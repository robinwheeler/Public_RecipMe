

Within this folder are 6 files.



The data sources for the model:

epi_r.csv and RecipeNLG.csv are clipped versions of larger datasets titled the same. They should be saved to the user's google drive "MyDrive" so they follow the path: /content/drive/MyDrive. They were clipped as they are too big for submission. The full datasets can be found here:

epi_r.csv: https://www.kaggle.com/datasets/hugodarwood/epirecipes
RecipeNLG.csv: https://www.kaggle.com/datasets/paultimothymooney/recipenlg




The model:

The RecipMe model is within the eponymously titled RecipMe.ipynb. It is a google colab file and should be used there. 




Analysis of RecipMe:

The script that analyses RecipMe is analysis_of_data.ipynb. It is a google colab file and should be used there. 




Two files of previously evaluated recipes (102) by both an LLM and human are here:

human_evaluated_recipes.json and human_evaluated_recipes.json. Both contain scoring on 5 criteria: fluency, relevance, correctness, structure, taste. However, in addition, human_evaluated_recipes.json contains human improved versions of the generated recipe. These, like the data sources, should be saved to the user's google drive "MyDrive" so they follow the path: /content/drive/MyDrive.
